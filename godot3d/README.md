# NO LIMITS: SURVIVAL 3D

Early Godot 4 mobile prototype (not a finished game).

Implemented: procedural outdoor test area, third-person character, first/third-person camera toggle, touch movement and looking, jump, simple buildings and trees.

Open `project.godot` in Godot 4. Exporting to Android requires Android export templates and a configured Android SDK. No APK is provided yet.

This is a new standalone Godot project in `godot3d/`; the original Android game is unchanged.
