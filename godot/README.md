# NO LIMITS SURVIVAL — Godot 4 3D foundation

This is a **separate Godot 4 prototype**, not a replacement for the working Java APK. It contains a procedural 3D forest, terrain, a river, a cabin, daylight, fog, a first-person camera, mobile touch movement and look controls, and a basic pickup interaction.

Open `godot/project.godot` in Godot 4.3+ and run the main scene. For Android export, install Godot Android export templates, configure an Android SDK and export preset. This branch does **not** yet produce an APK.

Visuals use generated primitive meshes and materials as a functional foundation. Photorealistic assets, characters, animations, and optimization remain future work.

Desktop controls: WASD movement, mouse look, E collect, Shift sprint, Escape release mouse. Mobile: left joystick, right drag to look, USE button.
