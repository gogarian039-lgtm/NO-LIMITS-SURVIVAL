# Умный симулятор (MVP)

Экспериментальная ветка Android-приложения на Kotlin. Выборы влияют на деньги, энергию, репутацию и финал. Прогресс сохраняется в SharedPreferences. Сервер не требуется.

## Сборка
Откройте ветку smart-simulator-mvp в Android Studio с Android SDK 35 и JDK 17. Выполните Gradle Sync и задачу assembleDebug. APK будет в app/build/outputs/apk/debug/app-debug.apk при успешной сборке.

## Статус
Исходники созданы, но APK ещё не собран и не проверен на устройстве. Дальше: JSON-сценарии, достижения, ежедневные испытания и платные дополнительные истории без блокировки базовой игры.
